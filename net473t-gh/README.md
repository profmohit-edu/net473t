# NET-473T

Academic course website for **Cloud Computing and Security (NET-473T)**, Department of Computer Science and Engineering, BVCOE, New Delhi.

## GitHub Pages Setup

Use a short repository name:

`net473t`

Upload these files to the repository root:

- `index.html`
- `styles.css`
- `README.md`

Then enable GitHub Pages:

`Settings -> Pages -> Deploy from branch -> main -> /root`

Suggested final URL:

`https://<github-username>.github.io/net473t/`

All course PPTs, watermarked PDFs, notes, question banks and reference resources remain hosted on Google Drive.

## SEO After Publishing

After the GitHub Pages URL is active, replace `YOUR-GITHUB-USERNAME` in:

- `robots.txt`
- `sitemap.xml`

Then submit the final URL and sitemap in Google Search Console.
