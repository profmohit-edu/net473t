Must Remember Definitions

  • Cloud computing: on-demand network access to shared configurable resources with rapid provisioning and measured service.

  • Shared responsibility: cloud provider and customer divide security duties according to service model.

  • Federated identity: authentication across organizational or cloud boundaries using trusted identity providers.

  • Least privilege: provide only required access, for required resources, under required conditions and duration.

  • Encryption: converting data into unreadable form using cryptographic keys.

  • Tokenization: replacing sensitive data with a substitute token while protecting the original mapping.

  • Secure SDLC: integrating security throughout software development phases.

  • DevSecOps: embedding security checks into development and operations pipelines.
