NET-473T Complete Exam Revision Guide

Use this guide after completing all four unit notes. It summarizes what students must know to prepare high-quality answers for Cloud Computing and Security.

Unit I: Cloud Foundations and Identity & Access Management

  • Cloud computing concepts and NIST characteristics: on-demand self-service, broad network access, resource pooling, rapid elasticity and measured service.

  • Cloud architecture: client layer, identity layer, management/control plane, data plane, compute, network, storage, logging and monitoring.

  • IaaS, PaaS and SaaS security responsibilities; why responsibility shifts but does not disappear.

  • Cloud security concepts: confidentiality, integrity, availability, accountability, isolation, governance and evidence.

  • Legal, compliance and industry standards: policy, regulatory obligations, audit trails and assurance evidence.

  • Federated identity: identity provider, service provider, SSO, SAML assertions, OAuth delegated authorization and OpenID Connect context.

Most expected long-answer areas:

  • Define cloud computing and explain its essential characteristics.

  • Explain cloud service models and shared responsibility.

  • Analyse security challenges in a multi-tenant cloud.

  • Explain federated identity management and least privilege.

Unit II: Cloud Infrastructure Security

  • Hybrid migration needs security planning before migration, during transfer, at cutover and during integration.

  • Pre-migration controls: asset inventory, data classification, dependency mapping, identity model, network design and rollback planning.

  • During migration: encrypted transfer, temporary-access governance, migration-tool security, validation and log preservation.

  • Integration risks: inconsistent policies, split monitoring, trust-boundary confusion and identity synchronization errors.

  • Configuration management: secure baselines, infrastructure as code, drift detection and exception handling.

  • Patch management: ownership, severity, testing, deployment windows, emergency patches and verification.

Most expected long-answer areas:

  • Explain security considerations during on-prem to cloud migration.

  • Analyse hybrid cloud integration risks.

  • Discuss configuration, patch and change management in cloud.

  • Explain cloud infrastructure audit with best practices.

Unit III: Cloud Data Security

  • Data states: data at rest, in transit and in use; each state needs identity, authorization, encryption, isolation and monitoring.

  • Data information lifecycle: create/collect, classify, store, use, share, archive and delete.

  • Foundational strategies: classification, minimization, ownership, access governance, retention, logging and incident readiness.

  • Encryption foundations: symmetric/asymmetric encryption, TLS, envelope encryption and cloud-managed versus customer-managed keys.

  • Egress monitoring: detect unusual exports, public sharing, unmanaged downloads and cross-region movement.

  • Masking hides selected fields; obfuscation reduces readability; anonymization aims to prevent re-identification; tokenization replaces sensitive values with tokens.

Most expected long-answer areas:

  • Differentiate data at rest, in transit and in use.

  • Explain the data information lifecycle in cloud.

  • Compare privacy transformation techniques.

  • Explain cloud key management audit and best practices.

Unit IV: Cloud Application Security, Secure SDLC and DevSecOps

  • Cloud application challenges: distributed services, API exposure, multi-tenancy, elastic infrastructure, third-party dependencies and operational complexity.

  • Application access to resources: workload identity, short-lived credentials, scoped permissions, tenant isolation and service-to-service authorization.

  • Common vulnerabilities: broken access control, cryptographic failures, injection, insecure design, misconfiguration, vulnerable components, authentication failure and logging gaps.

  • Cloud software assurance: security requirements, architecture review, code review, testing, dependency scanning, penetration testing and release evidence.

  • Secure SDLC: security requirements, threat modelling, secure design, secure coding, verification, release controls, monitoring and continuous improvement.

  • OWASP Top 10: use as an awareness and review framework, not a complete checklist.

Most expected long-answer areas:

  • Explain cloud application security challenges.

  • Discuss Secure SDLC for cloud applications.

  • Apply OWASP Top 10 to cloud application risks.

  • Design a DevSecOps pipeline for secure cloud deployment.

Universal 15-mark Answer Structure

  • Introduction/definition: 2 marks

  • Architecture/lifecycle/process explanation: 4 marks

  • Security risks/challenges: 3 marks

  • Controls/best practices: 4 marks

  • Audit/evidence/conclusion: 2 marks

One-Day Revision Strategy

  • Revise Unit I terminology and IAM diagrams.

  • Prepare one migration case for Unit II.

  • Memorize data states, lifecycle and key-management flow for Unit III.

  • Prepare OWASP + Secure SDLC + DevSecOps integrated answer for Unit IV.

  • Practice at least one 15-mark answer from every unit.
